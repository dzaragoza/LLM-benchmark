Which model should you run on your machine? This study measured nine small language-model families (0.8B to 3B parameters) doing real long-context work on a laptop-class CPU, then certified each one with a confidence level. Reliable means the model passed a repeated hidden-word retrieval test at that context size with 1-sigma confidence; conservative means the same claim at the stricter 2-sigma level. Every recommendation below is a model that was actually measured doing the task — not a vendor's claimed context window. Serving from a GPU instead? GPU picker.
Any machine with higher bandwidth than the options below (over 102.4 GB/s) will run the same models without issue — the list stops at the study's top measured class.
Configurations whose bandwidth cannot run any measured model (below  GB/s) are not listed.
Prefilled with the minimum RAM needed to run a certified model (3.48 GiB, the cheapest configuration); any machine with more memory runs the same models.

How the recommendation is computed. The study ran each model family 21 times per context size up a doubling ladder of context sizes (4k, 8k, 16k, … 256k tokens). At each context size the model had to find hidden words in a long coded text (a frequent-word-extraction task) — pass means it found at least 1 of the 3 hidden words. A context size counts as reliable when the pass rate is high enough that the 1-sigma confidence lower bound on the pass probability is at least 50% (a Wilson score interval; at n=21 that means about 13 of 21 passes). Conservative doubles the confidence requirement (2 sigma, about 16 of 21). The recommended model is the deepest reliable one that (a) fits your RAM (measured whole-stack cost: weights + KV cache + buffers + runtime, cold) and (b) is predicted to stay above the 5 w/s reader line at your bandwidth (speed scales linearly with memory bandwidth: measured@102.4×BW/102.4).

Why only three models? Nine families were measured (Qwen3.5 0.8B/2B, Jamba2-3B, Llama-3.2-1B, MiniCPM5 1B/2B, Jamba-Reasoning-3B, RWKV7-2.9B, gemma-3-1B). Six of them did not pass the retrieval test reliably at any context size — including some models with large advertised context windows. They are excluded rather than listed with misleading numbers; the full log is in the study's lab notebook. The three shown all certified at 4k/8k; deeper certifications are being measured now. Each family appears once, at its measured configuration.

Caveats: w/s figures are the median of 5 conversations at each model's reliable depth. Reliable/conservative depths are certified under the 1-of-3-words pass rule at n=21 runs (repetition gives the confidence; the threshold is stated). Certification at 16k and deeper is in progress — empty cells there mean "not yet certified", not "failed". The bandwidth law is validated only at the 102.4 GB/s class. Minimum-RAM values are run-shaped: treat the fit boundary as soft within ~1 GiB.
